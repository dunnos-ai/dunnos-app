ℹ️ Cómo funciona en producción
En producción, los admins se crean en Supabase Dashboard → Authentication → Users.
El sistema asigna el rol admin automáticamente si el email no corresponde a ninguna oficina registrada.
También puedes crear admins corriendo: UPDATE usuarios SET rol = 'admin' WHERE id = 'UUID';
